# Money Factory: working notes for Claude

## How we work (owner's standing instruction)
Treat this project as a hivemind / office operation. The lead Claude session is the boss: it plans,
splits work into independent pieces, spawns as many subagent workers as useful (in parallel, in the
background), reviews and integrates what they produce, and keeps the owner posted. Don't hold back
on delegation; token budget is not the constraint. Give each worker a clear brief, a disjoint set of
files/directories it owns, and a definition of done. Never let two workers edit the same files.

## Project layout
- `packages/shared`: types, WebSocket event union, Zod schemas for every agent role's output
- `apps/server`: Fastify + ws + SQLite (better-sqlite3), Claude Agent SDK runner, pipeline, yard gateway
- `apps/web`: React + Vite + Tailwind panels, PixiJS factory scene (`src/factory`)
- `assets/`: swappable sprite sheets (generated by `scripts/gen-assets.ts`)
- `docs/DESIGN.md`: architecture, schema, prompts, tier mapping

## Rules that must not be broken
- Web-reading roles (scout/research/market/validation) never get wallet or email tools.
- Executors only reach the wallet/email through the yard gateway (`apps/server/src/execution/gateway.ts`).
- Live execution stays off unless `ENABLE_LIVE=true` (phase 6, after the owner reviews paper results).
- Audit log, actions, ledger and P&L are append-only; no delete endpoints.

## Commands
- `npm run dev:mock`: full app with mock agents and mock wallet/email ($0)
- `npm run typecheck`, `npm test`
